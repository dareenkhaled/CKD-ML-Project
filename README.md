# Chronic Kidney Disease Prediction Using Machine Learning

This project applies machine learning techniques to predict chronic kidney disease risk using clinical patient data.

## Project Workflow

- Data cleaning and preprocessing
- Exploratory data analysis
- Feature engineering and selection
- Model training using different algorithms
- Model evaluation using accuracy, precision, recall, F1-score, and confusion matrix
- Deployment using Streamlit

## Best Model

Random Forest was selected as the final model because it achieved the best overall performance compared with the other tested algorithms.

## Repository Structure

- Machine_learning_Project_dareen.ipynb → Main notebook containing preprocessing, training, and evaluation
- app.py → Streamlit deployment file
- kidney_disease_dataset.csv → Dataset used in the project
- scaler.pkl → Saved scaler model
- requirements.txt → Required Python libraries


## Conclusion

This project demonstrates how machine learning can support medical prediction systems using patient clinical data. The trained model can help classify patients based on chronic kidney disease risk with good performance.
